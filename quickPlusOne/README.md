# QuickPlusOne

## 简介

`QuickPlusOne` 会在消息悬浮菜单里加入一个 `+1` 按钮，方便你快速复读别人发过的文本内容。

## 使用方式

1. 把鼠标移到一条消息上，打开消息悬浮菜单。
2. 按住 `Shift`。
3. 点击出现的 `+1` 按钮。

根据设置不同，点击后会有两种行为：

- 默认行为：把原消息的文本插入当前输入框。
- 开启 `autoSend` 后：直接把原消息文本发送到当前频道。

## 设置项

- `autoSend`：是否点击后立即发送，默认关闭。

## 行为细节

- 只有按住 `Shift` 时，`+1` 按钮才会显示。
- 只处理消息的文本内容，也就是 `msg.content`。
- 会保留原文本内容本身，包括换行等普通文本结构。

## 注意事项

- 如果目标消息没有文本内容，插件不会执行复制或发送，而是提示“该消息没有文本内容”。
- 图片、附件、Embed、贴纸之类的非文本内容不会被一并复用。
