# QuickBlock

## 简介

`QuickBlock` 会在消息悬浮菜单里加入一个快速屏蔽按钮，让你在按住 `Shift` 时直接屏蔽发言者，不再弹出额外确认。

适合处理“看到一条消息就想立刻拉黑”的场景。

## 使用方式

1. 把鼠标移到一条消息上，打开消息悬浮菜单。
2. 按住 `Shift`。
3. 点击出现的“屏蔽用户”按钮。

屏蔽成功后会弹出 toast 提示。

## 行为细节

- 只有按住 `Shift` 时，这个按钮才会显示出来。
- 对自己的消息不会显示该按钮。
- 已经被屏蔽的用户也不会重复显示该按钮。
- 实际调用的是 Discord 的关系接口，等价于直接执行一次原生屏蔽。

## 注意事项

- 这个插件不会二次确认，点下去就会直接屏蔽，请谨慎使用。
- 取消屏蔽需要回到 Discord 原生的好友 / 隐私相关入口手动处理。
- 依赖 `MessagePopoverAPI`，如果消息悬浮按钮体系不可用，这个插件也不会出现。
