# KeywordFilter

## 简介

`KeywordFilter` 用来按关键词或正则表达式隐藏消息。只要一条消息命中任意一条规则，这条消息就会在你的客户端里被直接隐藏。

适合拿来过滤你不想看的关键词、固定格式内容，或者更复杂的文本模式。

## 使用方式

在插件设置里添加规则即可：

- 普通模式下，规则会按“不区分大小写的子串匹配”处理。
- 点击每条规则右侧的 `.*` 按钮，可以切换成正则模式。
- 只要有一条规则匹配成功，这条消息就会被隐藏。

## 匹配逻辑

- 普通关键词：使用不区分大小写的包含匹配。
- 正则规则：使用 `i` 标志编译，同样不区分大小写。
- 多条规则之间是“或”关系，只要命中任意一条就隐藏。
- 无效正则不会生效，但会在设置界面里给出错误提示。

## 正则诊断

设置界面会额外分析正则，帮助你提前发现问题，例如：

- 语法错误
- 几乎匹配所有消息的模式
- 嵌套量词导致的潜在灾难性回溯
- 过多的贪婪通配符
- 反向引用、环视、超长表达式或分支过多

这些提示不会阻止你保存规则，但可以帮助你避免把过滤器写得太重。

## 行为细节

- 只检查 `message.content`，不会去匹配附件、图片、Embed、用户名、昵称或其他消息元数据。
- 规则变更后会重建缓存，已渲染消息之后会按新规则继续判断。
- 为了减少重复计算，插件会缓存最近一批消息的匹配结果。
- 旧版本里如果曾经把规则存进过 `rules` 字段，插件会在启动时自动迁移到新的 `keywords` 存储结构。

## 注意事项

- 普通关键词不是整词匹配，而是“包含就算命中”，所以短词可能会误伤更多内容。
- 正则虽然更灵活，但也更容易写出性能很差的规则。看到 warning 时最好认真检查一下。
- 这个插件是客户端本地隐藏，不会影响别人看到的内容。
