# ScrollToTop

## 简介

`ScrollToTop` 会在频道顶部工具栏加入一个“回到最上方”按钮，点一下就能快速跳到频道顶部，不需要手动猛拉滚动条。

## 使用方式

- 打开普通文本频道、媒体频道或线程时，顶部工具栏会出现一个向上的按钮。
- 点击它后，插件会直接把当前视图跳到该频道最上方。

## 适用范围

- 普通文字频道
- 媒体频道
- 公告线程、公开线程、私密线程

论坛频道主页不会显示这个按钮。

## 行为细节

- 按钮会插入在频道头部工具栏里，而不是消息区内部。
- 插件内部做了去重处理，不会因为重复渲染把按钮插入多次。
- 没有额外设置项，启用即可使用。

## 注意事项

- 这是一个纯客户端便捷功能，不会影响频道本身的数据或排序。
- 如果 Discord 后续改动频道头部工具栏结构，这类基于补丁插入的按钮可能需要重新适配。
